Command reference

Issue one command per line, or separate commands with a semicolon. Commands apply immediately; use Run or Step to advance time.

HEADING DLH101 250Set a heading in degrees
ALTITUDE DLH101 5000Set altitude in feet above airport level
SPEED DLH101 210Set airspeed in knots
DIRECT DLH101 NORTHFly to NORTH, EAST, SOUTH, or WEST
DIRECT DLH101 10 15Fly to local coordinates, nautical miles
HOLD DLH101Enter an airborne holding pattern
APPROACH DLH101 25RAssign an approach and landing runway
TAKEOFF DLH102 25CClear a waiting departure for takeoff
GO_AROUND DLH101Discontinue an approach
DIVERT DLH101Send a flight to an alternate airport
The selected controller issues commands when automatic control is enabled. Both LLM controllers remember previous observations, decisions, and their operational plans. Inference pauses simulation time. After the model responds, the selected decision window advances immediately. Larger windows run more simulated time per call but give the controller fewer chances to react. The speed selector applies to reference playback. Pause stops after the current decision completes. Switch automatic control off to control the episode yourself. Runway assignment does not guarantee a safe approach: monitor spacing, weather, and aircraft limits.
